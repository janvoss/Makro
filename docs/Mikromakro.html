4  Die Mikroökonomik der Makroökonomik

NoteMikrofundierung der Makro und der aktuelle Nobelpreis

Der Wirtschaftsnobelpreis 2026 geht an die beiden US-Ökonomen Robert E. Hall und Michael Woodford für ihre bahnbrechenden Arbeiten zu den „mikroökonomischen Grundlagen der makroökonomischen Stabilisierung“.

Die Auszeichnung würdigt die wissenschaftliche Leistung, makroökonomische Modelle und geldpolitische Konzepte konsequent auf dem optimierenden Verhalten einzelner wirtschaftlicher Akteure – also auf einer soliden Mikrofundierung – aufzubauen.

Was bedeutet Mikrofundierung?

Historisch basierte die makroökonomische Krisensteuerung (wie der klassische Keynesianismus) oft auf rein statistischen Zusammenhängen zwischen aggregierten Größen wie Gesamtkonsum, Inflation und Arbeitslosigkeit. In den Krisen der 1970er-Jahre scheiterten diese Modelle, da sie die Verhaltensanpassungen der Menschen ignorierten (die sogenannte Lucas-Kritik).

Hall und Woodford leiteten gesamtwirtschaftliche Phänomene strikt aus den Entscheidungen rationaler Individuen:

  • Das Mikro-Fundament: Anstatt den Konsum als feste makroökonomische Quote zu betrachten, analysierten sie detailliert, wann einzelne Haushalte sparen oder konsumieren und wann Firmen ihre Preise anpassen.

  • Die mikroökonomische Stabilisierung: Weil Märkte aufgrund von verzögerten Preis- und Lohnanpassungen (Nominelle Rigiditäten) nicht sofort ins Gleichgewicht finden, können staatliche Eingriffe angebracht sein.

4.1.1 Die intertemporale Budgetrestriktion

  • Haushalte wollen in jeder Periode konsumieren und verwenden dafür Einkommen.

  • Hier angenommen: 2 Perioden \(t\) und \(t+1\)

  • Zunächst angenommen: In jeder Periode ein exogenes Einkommen \(Y_t\) bzw. \(Y_{t+1}\)

  • Zum Zinssatz \(r\) kann Einkommen zwischen beiden Perioden verschoben werden (durch Sparen oder Kreditaufnahme). Es gibt keine exogene Begrenzung der Kreditaufnahme oder der Ersparnis

    • In Periode \(t+1\) endet jedoch der Planungshorizont für alle und in dieser Periode müssen alle Kredite zurückgezahlt sein.

    • Niemand hat einen Anreiz in Periode \(t+1\) zu sparen.

  • Budgetrestriktion: \[\text{Periode }t\text{: }C_t + S_t \le Y_t\], \[\text{Periode }t+1\text{: }C_{t+1} + S_{t+1} \le Y_{t+1} + (1 + r_t) S_t\]

  • Nach den zwei Perioden endet annahmegemäß der Planungshorizont. Niemand wird dem Haushalt in Periode \(t+1\) einen Kredit geben. Es gilt daher \(S_{t+1}=0\)

  • Daher gilt auch

\[C_t + S_t = Y_t\]

und

\[C_{t+1} = Y_{t+1} + (1 + r_t) S_t\]

\[ \iff S_t = \frac{C_{t+1}}{1 + r_t} - \frac{Y_{t+1}}{1 + r_t} \]

  • Daher

\[\boxed{C_t + \frac{C_{t+1}}{1 + r_t} = Y_t + \frac{Y_{t+1}}{1 + r_t} }\] \(\Rightarrow\) Der Barwert des Konsums muss also dem Barwert des Einkommens entsprechen

\(\Rightarrow\) Das Timing des Konsums lässt sich also (zumindest teilweise) vom Timing der Einkommenszuflüsse entkoppeln

Die Budgetgerade lautet also: \[\boxed{C_{t+1} = (1 + r_t)(Y_t - C_t) + Y_{t+1}}\]

library(ggplot2)

4.1.2 Die intertemporale Nutzenfunktion

Individuen/Haushalte erhalten in jeder Periode Nutzen \(u\) aus Konsum \(C_t\) bzw. \(C_{t+1}\).

Der intertemporale Gesamtnutzen \(U\) ist die gewichtete Summe des Nutzens in den Perioden. Der Konsum in \(t+1\) wird mit \(\beta \in[0;1]\) gewichtet.

\(\beta = \frac{1}{1+\rho}\) und \(\rho\), \(\rho\) ist der subjektive Diskontfaktor

\[ U = u(C_t) + \beta u(C_{t+1}) \]

\(U\): Gesamtnutzen über beide Perioden.

\(C_t, C_{t+1}\): Konsum in der heutigen (\(t\)) und zukünftigen Periode (\(t+1\)).

\(u(\cdot)\): Periodennutzenfunktion.

Annahme: \(u'(C) > 0\) (positiver Grenznutzen) und \(u''(C) < 0\) (abnehmender Grenznutzen).

\(\beta\): Subjektiver Diskontfaktor (\(0 < \beta < 1\), wobei \(\beta = \frac{1}{1+\rho}\) und \(\rho\) die Zeitpräferenzrate ist). Misst die Ungeduld der Haushalte.

Code 
library(ggplot2)
library(patchwork)

options(scipen = 999)

# --- Parameter (hier direkt anpassen) ---
sigma    <- 1.0   # Substitutionselastizität (σ = 1 entspricht Log-Nutzen)
beta_val <- 0.95  # Diskontfaktor (β)

# --- Hilfsfunktionen ---

# 1. Nutzenfunktion u(c)
u_func <- function(c, s) {
  if (abs(s - 1) < 1e-5) return(log(c))
  return((c^(1 - s)) / (1 - s))
}

# 2. Indifferenzkurve (berechnet C_{t+1} für ein gegebenes Nutzenniveau U)
get_c_future <- function(c_t, target_U, s, beta_val) {
  # U = u(C_t) + beta * u(C_{t+1})  =>  u(C_{t+1}) = (U - u(C_t)) / beta
  u_c_future_val <- (target_U - u_func(c_t, s)) / beta_val
  
  if (abs(s - 1) < 1e-5) {
    return(exp(u_c_future_val))
  } else {
    term <- u_c_future_val * (1 - s)
    return(ifelse(term > 0, term^(1 / (1 - s)), NA))
  }
}

# --- Datenberechnung ---

# Referenz-Nutzenniveau festlegen (Ankerpunkt Ct = 50, Ct+1 = 50)
c_ref <- 50
U_target <- u_func(c_ref, sigma) + beta_val * u_func(c_ref, sigma)

# Konsumwerte für die X-Achse generieren
c_vals <- seq(5, 150, length.out = 500)

# Dataframe für Plot 1 (Nutzenfunktion)
df_left <- data.frame(
  c_t  = c_vals,
  util = u_func(c_vals, sigma)
)

# Dataframe für Plot 2 (Indifferenzkurve)
df_right <- data.frame(
  c_t = c_vals
)
df_right$c_future <- sapply(df_right$c_t, function(c) get_c_future(c, U_target, sigma, beta_val))


# --- Erstellung der ggplot2-Diagramme ---

# Plot 1: Nutzenfunktion u(Ct)
p1 <- ggplot(df_left, aes(x = c_t, y = util)) +
  geom_line(color = "darkgreen", linewidth = 1.2) +
  labs(
    title = "Nutzenfunktion u(Ct)",
    subtitle = if(abs(sigma - 1) < 0.05) "Spezialfall: Log-Nutzen" else "CRRA-Nutzenfunktion",
    x = expression(paste("Konsum heute (", C[t], ")")),
    y = "Nutzenwert"
  ) +
  theme_minimal(base_size = 13)

# Plot 2: Indifferenzkurve
p2 <- ggplot(df_right, aes(x = c_t, y = c_future)) +
  geom_line(color = "#0072B2", linewidth = 1.2, na.rm = TRUE) +
  coord_cartesian(xlim = c(0, 150), ylim = c(0, 150)) +
  labs(
    title = "Indifferenzkurve",
    subtitle = "Kombinationen für gleiches U",
    x = expression(paste("Konsum heute (", C[t], ")")),
    y = expression(paste("Konsum morgen (", C[t+1], ")"))
  ) +
  theme_minimal(base_size = 13)

# --- Nebeneinander anordnen und anzeigen ---
combined_plot <- p1 + p2
print(combined_plot)

4.1.3 Intertemporale Konsumoptimierung

4.1.3.1 Allgemeine Gleichung für zwei Perioden

Der Haushalt muss folgendes Problem lösen:

\[\max_{C_t, C_{t+1}} \quad U = u(C_t) + \beta u(C_{t+1})\] u.d.N.

\[C_t + \frac{C_{t+1}}{1 + r_t} = Y_t + \frac{Y_{t+1}}{1 + r_t}\] \(C_{t+1}\) ergibt sich aber aus der Entscheidung über \(C_t\).

Umformulieren und einsetzen

\[C_{t+1} = (1 + r_t)(Y_t - C_t) + Y_{t+1}\]

\[\max_{C_t} \quad U = u(C_t) + \beta u\left((1 + r_t)(Y_t - C_t) + Y_{t+1}\right)\]

\[\frac{\partial U}{\partial C_t} = u'(C_t) + \beta u'\left((1 + r_t)(Y_t - C_t) + Y_{t+1}\right) \times -(1 + r_t)\stackrel{!}{=}0\]

\[\iff u'(C_t)=\beta u'(\underbrace{(1+r)(Y_t-C_t)+Y_{t+1}}_{C_{t+1}})\]

Das führt zu der Euler-Bedingung

\[\boxed{u'(C_t) = \beta (1 + r_t) u'(C_{t+1})}\]

  • Der korrigierte Grenznutzen muss in beiden Perioden gleich sein.

Korrigiert um

  • den Diskontfaktor \(\beta\). \(\beta\) misst die Geduld. Je niedriger zukünftiger Nutzen gewichtet wird (je geringer die Geduld ist), desto höher muss der zukünftige Grenznutzen sein;

  • den Zinssatz \(r\). \(r\) ist der Preis der Ungeduld und die Belohnung für Geduld. Je höher der Preis der Ungeduld ist, desto mehr Konsum in die Zukunf geschoben und desto niedriger muss der zukünftige Grenznutzen sein.

  • wenn gilt: \(\beta= \frac{1}{1+r}\), gleichen sich die Grenznutzen genau aus.

4.1.3.2 Grafische Herleitung für zwei Perioden

Aus der Euler-Gleichung lässt sich schreiben

\[u'(C_t) = \beta (1 + r_t) u'(C_{t+1})\]

\[\iff -\frac{u'(C_t)}{\beta u'(C_{t+1})}=-(1+r)\]

\[\iff MRS=\text{Steigung der Budgetgerade}\]

Code 
# Lade notwendige Bibliothek
library(ggplot2)

# ==========================================

# ==========================================
beta <- 0.875

# Wir berechnen die Utility-Level so, dass die Kurven exakt
# durch die gewünschten visuellen Koordinaten verlaufen.
U0 <- log(1.4) + beta * log(3.8)
U1 <- log(2.0) + beta * log(3.5)
U2 <- log(2.3) + beta * log(6.0)

# Funktion der Indifferenzkurve (Umgestellt nach C_{t+1})
# U = ln(C_t) + beta * ln(C_{t+1})  =>  C_{t+1} = exp((U - ln(C_t)) / beta)
IC <- function(x, U) { exp((U - log(x)) / beta) }

# Koordinaten der relevanten Punkte: Endowment (Y), P0, P3 (Tangentialpunkt), P2, P1
